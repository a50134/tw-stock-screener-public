    每日 SOP
    
      
    
        
    
          
    國際情勢
    
            
    
          
    
          
    
          
      
          
      
          
      
        
      
        
        
          
      1. ① 初篩：用策略找出觀察名單 
        
            
        用你在左側建好的任一組策略。建議先用「營收成長＋外資連買」或「三率三升＋土洋合作」這類基本面＋籌碼的策略，名單比較穩。
        
            
        2. 
          
      2. ② 淘汰：刪掉不合格的 
        
            
        
            
        3. 
          
      3. ③ 健檢：只留  分以上 
        
            
        健檢分數 = 營收、獲利、籌碼、技術、風險五大面向的得分（缺資料的項目不計）。點下方表格的股票可看完整健檢報告。
        4. 
          
      4. ④ 隔天早上：填入開盤價或目前價，判斷買不買
        
            
        
              
        可買價格在參考買進區間內（交易計畫「等拉回」的股票，拉回到區間就是買點）、開盤漲幅低於 %、沒有跌破停損價。國際風險「高」時只買一半。
        
              
        等待價格高於「不追價」→ 掛單在不追價以下等回檔；低於區間下緣 → 等止跌收紅再說；交易計畫顯示「等拉回／等站回月線」。
        
              
        不要買跳空大漲 ≥ %、開低 ≤ −%、跌破停損價、健檢 D 級。
        
            
        
            
        
            
        網頁拿不到即時報價：開盤後請自己從看盤軟體把價格填進「今日價格」，判斷會立刻更新。價格只記在這台瀏覽器，換選股日期會清空。
        5. 
        
      
        
      
          
      匯出到 Discord／LINE
      
          
      
            
      
          
          
      複製後可以直接貼到 Discord 頻道或 LINE 聊天室。每天自動發送：按「複製排程設定」，把內容存成每日報告資料夾裡的 sop_config.json，排程就會用你現在的策略、淘汰條件和自選股。手動發送：執行 python send_report.py，它會讀剪貼簿，送到你設定的 Discord Webhook 和 LINE 官方帳號（腳本在「資料來源」可以複製）。
      
        
      
        
      每日時間表與原則（建議照這個順序做）
        
          
      1. 前一天收盤後（晚上）：執行 python fetch_finmind.py 更新並匯入 data.json → 看步驟 ①②③ 的最後名單 → 每檔點開看「健檢報告」和「交易計畫」，把想買的加到自選股（★）。
        2. 
          
      2. 早上 8:00–8:45：執行 python fetch_finmind.py --macro，匯入產生的 macro.json 更新國際新聞 → 看「國際情勢」風險。川普、聯準會、台海這類消息多的日子，把判斷改成「中」或「高」。也順便看美股收盤和台指期夜盤。
        3. 
          
      3. 9:00–9:15 開盤：先不要下單。把每檔的開盤價填進步驟 ④。
        4. 
          
      4. 9:15–10:00：只買「可買」的，分兩批進場；「等待」的掛單在不追價以下；「不要買」的今天直接放棄。
        5. 
          
      5. 盤中：收盤價跌破停損價就出場，不要凹單、不要攤平。
        6. 
          
      6. 收盤後：看持股的「賣出訊號」。出現 2 個以上賣出訊號，或到第一目標，就分批獲利了結。
        7. 
          
      7. 資金原則：單筆最多虧總資金 2%（資金試算會幫你算股數）；國際風險高時部位減半；同時持有不超過 5 檔。
        8. 
        
      
      
      
    
      
    
      
      
      模擬下單
      
      
      
        
      
          
          
          
          
          
          
          
          
        
      
        
      
        
      
        
      
        
      
        
        
      用每天的日K判斷：買進單在最低價 ≤ 限價時成交（開盤就比限價低則以開盤價成交），賣出單在最高價 ≥ 限價時成交。「有效」是掛單幾個交易日。手續費用「資金試算」的折數，零股最低 1 元、整股最低 20 元；賣出證交稅股票 0.3%、ETF 0.1%。零股實際成交價可能和整股略有不同。下單記在這台瀏覽器；按「複製排程設定」後，每日報告也會附上這段。
